# Download Manager for PC

A free, open source download manager for Windows, macOS, Linux and BSD. It splits each file across up to 64 connections, keeps your downloads in queues and runs them on your schedule. If you are looking for a free IDM alternative, it covers the same core jobs at no cost.

**[Download from SourceForge](https://sourceforge.net/projects/download-manager/)**

## Features

- **Multithreaded downloads:** up to 64 connections for each file. The gain depends on your connection and on the server, since some servers limit connections.
- **Download queues:** files wait their turn and stay organized.
- **Download scheduler:** run large downloads at the time you choose.
- **Video downloads:** find and download videos from sites such as YouTube, Vimeo and DailyMotion with yt-dlp.
- **Browser extension:** send links to the app from Chrome, Chromium, Firefox, Opera and Vivaldi.
- **Clipboard import:** copy a link and add it to the app.
- **Socks5 proxy:** route downloads through a proxy if your network needs one.

## Supported systems

Windows, macOS, Linux and BSD. All builds are published on the [SourceForge project page](https://sourceforge.net/projects/download-manager/).

## FAQ

**Is this download manager free?**
Yes. It costs nothing and is released under GPLv3.

**Is it an open source download manager for Windows?**
Yes. The source code is in this repository.

**Is it a free IDM alternative?**
It is a free alternative to Internet Download Manager for multi-connection downloads, queues, scheduling, video and browser integration. This project is not affiliated with Internet Download Manager or Tonec Inc.
