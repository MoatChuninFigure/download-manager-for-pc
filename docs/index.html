A free, open source download manager app. It splits each file across up to 64 connections, keeps your downloads in queues and runs them on your schedule.

Multithreaded download manager

This download manager software splits each file into as many as 64 parts and fetches them over separate connections at the same time. The gain depends on your connection and on the server, since some servers limit how many connections they accept.

How to speed up downloads on PC

Use more connections. A multithreaded download uses more of the bandwidth you already have, which matters most for large files on servers that allow several connections.

Move big downloads to quiet hours. Set the scheduler for a time when nobody else on your network needs it.

Keep the rest in a queue. Files wait their turn, so your other downloads stay organized.

Video download manager for PC

Paste a page link and the app finds the video with yt-dlp, then downloads it like any other file. Use it as a download manager for YouTube videos, or for Vimeo and DailyMotion.

Download manager Chrome extension

A browser extension hands links to the app, so you can keep browsing while files download. It is available for Chrome and Chromium, and there is also a download manager for Firefox, Opera and Vivaldi users.

Without an extension, copy a link and the app can import it from the clipboard.

A download manager for Windows, Mac and Linux

Use the same download manager app on Windows 10, Windows 11, macOS, Linux and BSD. Downloads can also go through a Socks5 proxy if your network needs one.

IDM alternative for Windows

Internet Download Manager is paid software. If you want an IDM alternative for PC with no price tag, this one covers the same core jobs: multi-connection downloads, queues, scheduling, video and browser integration. It is also open source, so anyone can read the code.

Download manager FAQ

What is the best download manager for PC?

It depends on what you download. For large files, look for multi-connection downloads. For a slow or shared network, look for a scheduler. If you want the best free download manager for your needs, compare a few, and start with open source ones you can inspect.

Is this download manager free?

Yes. You can get this download manager free from SourceForge, and it is released under the GPLv3 license.

Is it an open source download manager for Windows?

Yes. It is licensed under GPLv3, and the source code is on GitHub.

How many connections can it use?

Up to 64 for each file. The server you download from may allow fewer.

Can it download videos?

Yes. It finds and downloads videos from sites such as YouTube, Vimeo and DailyMotion using yt-dlp.

Which systems does it run on?

Windows, macOS, Linux and BSD.
